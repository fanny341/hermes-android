## Task 3: Regenerate last response

**Objective:** Add a "Regenerate" button that resends the last user message to get a new response.

**Files:**
- Modify: `lib/core/screens/chat_screen.dart`

**Step 1: Add a regenerate icon in the overflow menu or as a button**

In the PopupMenuButton actions (or as a dedicated button in the app bar):

```dart
// In the three-dot menu or as an IconButton when not streaming
if (!_streaming && _messages.isNotEmpty && _messages.last['role'] == 'assistant')
  IconButton(
    icon: const Icon(Icons.replay),
    tooltip: 'Regenerate',
    onPressed: () => _regenerate(),
  ),
```

**Step 2: Implement `_regenerate`**

```dart
void _regenerate() {
  // Find the last user message
  final lastUserIdx = _messages.lastIndexWhere((m) => m['role'] == 'user');
  if (lastUserIdx < 0) return;

  // Remove the last assistant response
  if (_messages.last['role'] == 'assistant') {
    setState(() => _messages.removeLast());
  }

  // Resend
  final lastUserText = _messages[lastUserIdx]['content'] as String? ?? '';
  _sendMessage(lastUserText);
}
```

**Step 3: Verify**

Send a message → get a response → tap regenerate → new response appears, old one replaced.

## Task 5: Show timestamps on individual messages

**Objective:** Display the time each message was sent/received inside the bubble, making the conversation timeline clear.

**Files:**
- Modify: `lib/core/screens/chat_screen.dart`

**Step 1: Parse timestamps from message metadata**

The API may return timestamps per message. Check if `msg['created_at']` or `msg['timestamp']` exists. Add a display helper:

```dart
String _formatMsgTime(dynamic ts) {
  if (ts == null) return '';
  final dt = DateTime.fromMillisecondsSinceEpoch(
    (ts is int ? ts : (ts as num).toInt()) * 1000,
  );
  return '${dt.hour.toString().padLeft(2, '0')}:${dt.minute.toString().padLeft(2, '0')}';
}
```

**Step 2: Add time label inside each bubble**

In `_MessageBubble`, add a time label at the bottom-right of the bubble:

## Task 6: Add `--split-debug-info` to release build

**Objective:** Strip debug symbols from the release APK to make it smaller. This is orthogonal to ProGuard and saves ~5-10 MB.

**Files:**
- Modify: `android/app/build.gradle.kts`

**Step 1: Add split-debug-info configuration**

In the `release` build type:

```kotlin
release {
    signingConfig = signingConfigs.getByName("release")
    isMinifyEnabled = true
    isShrinkResources = true
    proguardFiles(
        getDefaultProguardFile("proguard-android-optimize.txt"),
        "proguard-rules.pro"
    )
}
```

Add to `defaultConfig` or as a Flutter build argument:

```kotlin
flutter {
    source = "../.."
}
```

In the CI command:
```yaml
- name: Build release APK
  run: flutter build apk --release --split-debug-info=build/debug-info
```

This strips symbol names from the Dart code, reducing APK size.

**Step 2: Verify**

APK size should drop by a few MB. Debug symbols are still recoverable from the `build/debug-info` folder if needed for crash analysis.

**Commit:**
```bash
git add .github/workflows/build-apk.yml
git commit -m "build: strip debug info from release APK"
```

## Task 7: Add unit tests for core models

**Objective:** Add basic unit tests for the Session model to catch parsing regressions.

**Files:**
- Create: `test/models/session_test.dart`
- Modify: `pubspec.yaml` (add `test` dependency if missing)

**Step 1: Create test file**

`test/models/session_test.dart`:

```dart
import 'dart:convert';
import 'package:flutter_test/flutter_test.dart';
import 'package:moritzu_hermes/core/models/session.dart';

void main() {
  group('Session.fromJson', () {
    test('parses complete session JSON', () {
      final json = jsonDecode('''
      {
        "id": "sess_123",
        "title": "Test Chat",
        "model": "hermes-agent",
        "source": "api",
        "message_count": 5,
        "started_at": 1700000000,
        "preview": "Hello, how can I help?",
        "ended_at": 1700003600,
        "is_running": false
      }
      ''') as Map<String, dynamic>;

      final session = Session.fromJson(json);

      expect(session.id, 'sess_123');
      expect(session.title, 'Test Chat');
      expect(session.model, 'hermes-agent');
      expect(session.source, 'api');
      expect(session.messageCount, 5);
      expect(session.isActive, false); // ended_at != null
      expect(session.isRunning, false);
      expect(session.preview, 'Hello, how can I help?');
      expect(session.startedAt, 1700000000);
      expect(session.endedAt, 1700003600);
    });

    test('parses active session without ended_at', () {
      final json = jsonDecode('''
      {
        "id": "sess_456",
        "title": "Active Chat",
        "model": "hermes-agent",
        "source": "api",
        "message_count": 3,
        "started_at": 1700000000,
        "preview": "",
        "is_running": true
      }
      ''') as Map<String, dynamic>;

      final session = Session.fromJson(json);

      expect(session.id, 'sess_456');
      expect(session.isActive, true);
      expect(session.isRunning, true);
      expect(session.endedAt, null);
    });

    test('handles missing fields gracefully', () {
      final session = Session.fromJson({});

      expect(session.id, '');
      expect(session.title, 'Untitled');
      expect(session.model, 'Default');
      expect(session.messageCount, 0);
      expect(session.isActive, true); // ended_at is null
      expect(session.isRunning, false);
      expect(session.preview, '');
      expect(session.startedAt, 0);
      expect(session.endedAt, null);
    });
  });

  group('Session equality', () {
    test('sessions with same id are equal', () {
      final a = Session.fromJson({'id': 's1', 'title': 'A'});
      final b = Session.fromJson({'id': 's1', 'title': 'B'});
      // Different titles but same id — they are the same logical session
      expect(a.id, b.id);
    });
  });
}
```
